# 🖼️ GIFs & Images Live Previewer

A lightweight, pure HTML/CSS/JavaScript web app that lets you **browse, preview, and filter images from any local folder** directly in your browser — with instant live thumbnails and format filtering.

---

## ✨ Features

- 📁 **Load any local folder** using the native directory picker  
- 🖼️ **Live image previews** generated instantly in a responsive grid  
- 🎞️ **Supports many formats**: PNG, JPG, JPEG, GIF, WEBP, SVG, BMP, TIFF/TIF, AVIF, ICO  
- 🎚️ **Filter by file type** with real-time updates  
- 📊 **Dynamic image counter** showing how many match the filter  
- 📋 **Quick filename list viewer** for the current filter  
- 🎨 **Modern glass-style dark UI**  
- ⚡ **No server, no install, no frameworks** — runs entirely in the browser  
- 🧹 **Memory-safe previews** using automatic object URL cleanup  

---

## 🚀 How to Use

1. **Download or clone** this repository  
2. Open **`index.html`** in any modern browser  
3. Click **“Load folder”**  
4. Choose a folder containing images or GIFs  
5. Use the **filter dropdown** to view specific formats  
6. Hover previews to see filenames and file types  

---

## 🛠️ Built With

- **Vanilla HTML, CSS, and JavaScript**
- Native **directory picker** (`webkitdirectory`)
- `URL.createObjectURL()` for fast local previews
- Responsive **CSS grid layout**
- No dependencies or build tools
